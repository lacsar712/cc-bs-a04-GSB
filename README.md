# 桥梁应变班交台

同一跨段须 **主测点 + 副测点成对双测**：测量员在一次提交里同时报两个微应变，
后台工人用 `FOR UPDATE SKIP LOCKED` 认领候审队列，按 **80～220 με** 判定 **合格** 或 **越界**。

## 双测规则

- **成对才许入队**：报送必须选择一个已登记的双测配对，并同一次提交主、副两个微应变；缺一退回。
- **差值门槛**：主副差值 `|主 − 副|` 绝对值超过门槛（默认 **10 με**，专页可调）→ **整笔退回**，
  不写入队列，在「退回样例」留痕，原因写明 **双测超差**。
- **配对随单冻结**：入队时把跨段、主/副测点编号、主副值、差值快照进单；
  事后在专页改配对表只影响新单，改不了旧单已冻结的点号。
- **一次写完、撞车唯一**：入队与冻结在同一事务内完成，先对配对行 `FOR UPDATE` 加行锁，
  配合在审部分唯一索引，两人并发交同一对 **至多一笔成功**，另一笔 409。
- **候审唯一**：同一配对在 `pending/processing` 期间至多一笔；判定为 `done` 后槽位释放，可再交。

## 角色权限

| 角色 | 报送 | 配对维护 | 差值门槛 | 查看配对/差值/退回样例 |
|------|------|----------|----------|------------------------|
| 测量员 surveyor | ✅ | ✅ 增/改 | ✅ | ✅ |
| 复核员 reviewer | ❌ 403 | ❌ 只读 | ❌ 只读 | ✅ |

## 双测配对专页

顶栏「**双测配对专页**」是独立页面（`#/pairs`），含三块：

1. **配对维护**：登记跨段的主/副测点编号、修改既有配对；
2. **差值门槛**：查看/设置双测超差门槛；
3. **退回样例**：历次双测超差整笔退回的留痕（主副值、差值、门槛、原因）。

> 首页报送表单里的两个输入框只是一次双测提交，**不是**配对维护入口。

## 技术栈

| 层 | 选型 |
|----|------|
| 接口 | Python Sanic + psycopg（异步连接池） |
| 工人 | `worker.py`（psycopg 同步，`FOR UPDATE SKIP LOCKED`） |
| 页面 | Mithril.js + Vite（`m.route` 双页），nginx 反代 `/api` |
| 数据库 | PostgreSQL 16 |

```bash
docker compose up --build
```

健康检查：`GET http://localhost:8198/api/health` → `{"status":"ok","service":"bridge-strain-shift"}`

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/auth/login` | 登录取 JWT |
| GET | `/api/pairs` | 双测配对表（测量员/复核员） |
| POST | `/api/pairs` | 登记配对（测量员） |
| PATCH | `/api/pairs/{id}` | 改配对（测量员；不动旧单快照） |
| GET | `/api/settings` | 差值门槛 |
| PUT | `/api/settings` | 设置差值门槛（测量员） |
| POST | `/api/readings` | 成对报送 `{pair_id, main_microstrain, sub_microstrain}` |
| GET | `/api/readings` | 队列（含冻结点号、主副值、差值） |
| GET | `/api/rejections` | 双测超差退回样例 |

报送返回：入队 `201`；双测超差 `422`（`detail` 写明双测超差）；同对在审撞车 `409`；
缺一值 `400`；配对不存在 `404`；复核员写操作 `403`。

## 验收样例

默认已配「**跨中甲**」主/副测点，门槛 10：

| 报送 | 主副差 | 结果 |
|------|--------|------|
| 主 150 / 副 155 | 5 | **进候审**（201，pending，配对随单冻结） |
| 主 150 / 副 190 | 40 | **整笔退回**（422，双测超差，写入退回样例） |

## 种子数据

默认配对：跨中甲（跨中甲-主 / 跨中甲-副）、支座S2（支座S2-主 / 支座S2-副）；
两条已办结双测样例；差值门槛 10 με。

## 本地开发（可选）

```bash
cd backend && pip install -r requirements.txt
python -m sanic api.app --host=0.0.0.0 --port=8000 --single-process
python worker.py
cd frontend && npm install && npm run dev
```

接口进程默认监听容器内 **8000**，对外映射 **8198**。
